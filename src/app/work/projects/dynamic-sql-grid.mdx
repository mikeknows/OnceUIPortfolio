## Project Overview

The Dynamic SQL Grid project demonstrates how database table columns are seamlessly mapped to user interface components, creating a responsive and interactive data visualization system. This solution bridges the gap between backend data structures and frontend user experience.

## Technical Architecture

### Backend SQL Structure
```sql
CREATE TABLE employees (
    id INT PRIMARY KEY,
    first_name VARCHAR(50),
    last_name VARCHAR(50),
    email VARCHAR(100),
    department VARCHAR(50),
    salary DECIMAL(10,2),
    hire_date DATE,
    status ENUM('active', 'inactive')
);
```

### Dynamic Column Mapping
The system automatically maps SQL columns to UI components:

```typescript
interface ColumnMapping {
  sqlColumn: string;
  displayName: string;
  dataType: 'string' | 'number' | 'date' | 'boolean';
  sortable: boolean;
  filterable: boolean;
  width?: number;
}

const columnMappings: ColumnMapping[] = [
  { sqlColumn: 'first_name', displayName: 'First Name', dataType: 'string', sortable: true, filterable: true },
  { sqlColumn: 'last_name', displayName: 'Last Name', dataType: 'string', sortable: true, filterable: true },
  { sqlColumn: 'salary', displayName: 'Salary', dataType: 'number', sortable: true, filterable: true },
  { sqlColumn: 'hire_date', displayName: 'Hire Date', dataType: 'date', sortable: true, filterable: true }
];
```

## Implementation Highlights

### Frontend Component (React)
```typescript
const DynamicGrid: React.FC<GridProps> = ({ tableName, apiEndpoint }) => {
  const [columns, setColumns] = useState<ColumnMapping[]>([]);
  const [data, setData] = useState<any[]>([]);
  
  useEffect(() => {
    // Fetch column schema from backend
    fetchColumnSchema(tableName).then(setColumns);
    fetchTableData(tableName).then(setData);
  }, [tableName]);

  return (
    <GridContainer>
      {columns.map(column => (
        <GridColumn 
          key={column.sqlColumn}
          mapping={column}
          data={data}
        />
      ))}
    </GridContainer>
  );
};
```

### Backend API (C# .NET)
```csharp
[HttpGet("schema/{tableName}")]
public async Task<IActionResult> GetTableSchema(string tableName)
{
    var columns = await _dbContext.GetColumnMappings(tableName);
    return Ok(columns.Select(c => new ColumnMappingDto
    {
        SqlColumn = c.ColumnName,
        DisplayName = c.DisplayName,
        DataType = c.DataType,
        Sortable = c.IsSortable,
        Filterable = c.IsFilterable
    }));
}
```
